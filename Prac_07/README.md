## What I Learned About Clean Code

During this subject, I gained several important lessons about writing clean and maintainable code:

- **Small, single-purpose functions**  
  Functions should do one thing only. This makes them easier to read, test, reuse, and debug.

- **Consistent naming and formatting**  
  Clear variable names, consistent indentation, and readable layout significantly improve code quality.

- **Separation of concerns (SRP)**  
  Logic, data handling, input/output, and validation should be separated.  
  This makes programs easier to extend without breaking other parts.
